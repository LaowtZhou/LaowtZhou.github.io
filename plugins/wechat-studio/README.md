手动排版公众号文章，在AI时代就像古法编程一样。

相信不少朋友已经用上公众号排版SKILL了，但仍免不了手动复制到公众号后台。

**我写完文章的那一刻，根本不再进入“排版”这道工序。**

这个工具从我刚开始恢复写公众号开始就用了，今天把它分享给大家，让大家都能轻松做出自己满意的排版。

WeChat Studio 是我在前人基础上开发的 Obsidian插件。

我在中间写文章，右边就是公众号手机预览；你在任意一边滚到文章中段，另一边跟着滚动；文章里的图片、封面、作者、摘要、评论开关和结尾名片，都由同一个 Markdown 文件接管。

最后点一下纸飞机，它不是给你导出一段 HTML，而是把**封面、正文图片、带内联样式的正文和文章元信息**一并同步到公众号草稿箱。

> **这不是“排版插件”。这是一个长在 Obsidian 里的公众号发布工作台。**

下面详细介绍一下主要功能
## 所见即所得

在我刚开始排版公众号的时候，我也是像很多人一样，让AI做成公众号兼容的HTML，然后复制过去。

这里面最大的问题就是我在写文章的时候不知道最终的样子，如果排版后发现有哪个地方看着不顺眼了，或者发现一个句子应该加粗强调一下，就要让AI重新做。

因为我不会编辑HTML。

后来我开始用Obsidian写文章，在 WeChat Studio 里直接就可以看到手机排版的样子。

![[Pasted image 20260811163015.png]]

我输入或者修改任何内容，预览都会自动刷新，而且文章和预览界面同步滚动，方便检查效果。

这件事看着小，但写过长文的人才知道有多爽。

你不再需要在几百上千行的 Markdown 里找引用块，也不需要来回拖滚动条猜标题落在手机上是什么效果。

你写到哪里，公众号就看到哪里。

真正的 0 秒，不是“生成得快”，而是**写作和验收发生在同一秒。**

![[assets/body/wechat-body-01-workflow.png]]

## 完全自由的风格库

我之前用的排版网站或者插件，样式都是别人固定死的，你只能选择预设好的风格，虽然少数网站支持你自定义，但不是完全的自定义。

而我觉得每个人的气质不同、品味不同，自然公众号文章的风格就应该不同，大家不能穿一条裤子看上去都一样。

就像我的Obsidian的皮肤就是自己自定义的，有赛博风、黑暗风、游戏风，但最后因为长时间使用考虑护眼，选了这个护眼色（笑）。

![[Pasted image 20260811164006.png]]所以我在开发 WeChat Studio 依然保持了完全开放的自定义样式。

现在插件里已经有 9 套预设样式。简洁正文、杂志感栏目、实用教程、线性科技、老顽童增长笔记……选风格不只是改字体和颜色。

![[Pasted image 20260811172347.png]]

不同的样式会把 H1、H2、H3 做成不同的章节结构；代码块会变成带窗口头的内容卡；有的预设会给文章自动加开篇栏目条和结尾收束；

也就是说，**你写的仍然只是干净 Markdown；读者看到的，却已经是一篇有栏目识别的公众号文章。**

这里我要叠个甲

我的审美能力是很普通的水平，做不出那种大神手下好看的样式，大家可以自己动手做出自己喜欢的样式。

我保证这很简单。

样式文件放在插件自己的 `presets` 目录，改完 CSS 和配置，工作台里点一下刷新就重新加载。

以后你发文只要直接选自己的样式，如果哪天你觉得需要新样式了，直接加一个就行。

![[assets/body/wechat-body-02-steps.png]]
## 真正叫绝的，是它把 Markdown 当 CMS

你以前写的 frontmatter，大概率只是在给 Obsidian 自己看。

在 WeChat Studio 里，它直接成了公众号文章的发布参数。

![[Pasted image 20260811164841.png]]

文件名就是公众号标题。

`author`、`digest`、`source_url`、`open_comment`，就是作者、摘要、原文链接和评论开关。封面可以指定 `banner_path`，也可以直接放已有的 `thumb_media_id`；实在没写封面，插件会拿正文第一张图片兜底。

你看，这已经不是“排版工具”了。这是一个面向发布的内容推送工具。

```yaml
---
author: 老顽童周老师
digest: 这里写摘要
banner_path: ./assets/cover.png
open_comment: true
---
```

它还支持把作者、摘要、来源链接、评论状态设成默认值。每天发文的人不用每篇重复填；少数文章要改，frontmatter 覆盖一次即可。

![[Pasted image 20260811165038.png]]

还可以自定义结尾

你可以设置四种模式：不加、只加尾图、只加公众号名片、尾图和名片都加。头像、名称、简介、辅助信息、底部引导语一次设好，以后每篇文章自动带上。

![[Pasted image 20260811165132.png]]

## 图片上传100%同步

有时候一些图片上传到公众号后会出现问题。

WeChat Studio 在发送前会先查：公众号连接配没配、封面有没有、正文里引用的图片是否正确、结尾配置的图片能不能找到。

缺任何一项，它都会直接拦住告诉你。

如果没有问题，几秒钟就会出现在你的草稿箱里。

如果你要修改图片，那只要在Obsidian里编辑后再次上传草稿就行。

## 从0起步使用方法

这个工具特别适用于想设计自己的视觉传达的作者，通过辨识度使用户能直观的辨别你的作品。

首先和没写过Markdown文件的小白说，我也是从小白起步的，上手并不困难，常用的格式就几种。

1. ‌**标题**‌：`#` 数量代表层级（1-6 级），需加空格，如 `# 一级` 、`## 二级`。
2. ‌**字体强调**‌：加粗用 `**文本**`，斜体用 `*文本*`，删除线用 `~~文本~~`。
3. ‌**列表**‌：无序用 `-`/`*`/`+` 开头，有序用 `1.` 开头；任务列表用 `- [x]`（完成）或 `- [ ]`（未完成）。
4. ‌**引用与代码**‌：引用用 `>` ；单行代码用 `` `代码` ``，多行代码块用三个反引号 ``` 包裹并可选语言标识。
5. ‌**图片**‌：直接复制粘贴就行，要选择图片其实是选择的一行文字。
6. ‌**分割线**‌：单独一行输入 `---` 或 `***`（至少 3 个）。
### 第一步：配置链接和账号设置

在插件栏点击齿轮进入插件设置，填写公众号后台的 AppID 和 AppSecret，再点“测试连接”。显示已连接就表示成功了。

 AppID 和 AppSecret 获取方式：微信开发者平台 → 我的业务与服务 → 公众号/服务号 → 进入详情页 → 基础信息。

![[Pasted image 20260811171651.png]]

需要的话顺手把默认作者、摘要、评论开关和结尾名片配置好。以后每篇文章都少填一遍。

### 第二步：准备完成编辑的文章

开头说过不少朋友可能用上排版SKILL了，其实准确的说，AI排版可能包括非常多的事情：
+ 识别文章段落标题层级，并给不同层级的文字赋予字体、字号、颜色；
+ 给需要强调的文字加粗，或者加引用框；
+ 给代码加代码块；
+ 加分割线或表格
+ 生成插图和封面

我看很多博主为了宣传一键完成排版把生图包含进去了，甚至还有把标题优化含进去的，其实都已经不属于排版SKILL的范畴了

我在文章定稿后会让AI按我的排版、生图、标题优化SKILL走一遍，完成后就可以待发布了。

所以AI和SKILL还是有用的，但应该分工明确。
###  WeChat Studio 预览

打开当前文章，点侧边栏插件入口。

右侧就是预览。第一次使用先别急着发，全部浏览一遍你的文章。

教程就用更利落的实用指南，栏目文可以选带开篇和结尾的编辑版，技术文用带代码卡片的风格。

已有预设不够？直接让AI帮你在 `presets` 目录增加或修改 CSS 和对应配置，再点插件的刷新按钮，工作台立刻重载。这个能力对有固定品牌感的人，比“提供 200 个花哨模板”实用得多。

### 最后点纸飞机，去草稿箱复核

插件只同步到公众号草稿箱，不替你直接发布。
## 这东西最适合谁

它不适合偶尔发一条通知、手工排两分钟也无所谓的人。

它适合的是已经用 Obsidian 写内容，又被“发布前最后十分钟”反复折磨的人：

- 一篇文章写完，却要在两个编辑器里维护两份版本；
- 每次发文都要重新传封面、传正文图、补摘要、补结尾；
- 有自己的视觉风格，却只能在公众号后台靠记忆一点点调；
- 写到长文中段，根本不知道手机上读起来会不会闷；
- 真正想把公众号当内容资产，而不是朋友圈长截图。

如果你属于其中任何一条，WeChat Studio 的价值就不是“效率提升了多少百分比”。

它是把公众号发布，从一个靠记忆和耐心的手工活，变成一个你能反复使用、能检查、能沉淀的流程。
