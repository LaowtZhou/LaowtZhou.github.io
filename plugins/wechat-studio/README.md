# WeChat Studio

WeChat Studio is an Obsidian plugin for previewing Markdown articles with switchable WeChat-style layouts and preparing them for publication.

## Manual installation

Copy this `wechat-studio` folder into:

```text
<your Obsidian vault>/.obsidian/plugins/wechat-studio
```

Then enable **WeChat Studio** in Obsidian's community plugins settings.

The plugin's local runtime configuration is intentionally excluded from this repository. Configure your own WeChat credentials inside the plugin settings after installation.
